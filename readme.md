# OmniPass

A cross-platform, offline-firts password manager built in java.

> Currently under development.

## Current Features

- Add password entries
- View saved passwords
- Save vault to disk
- Load vault from disk
- offline first

## Planned Features -

- Search passwords
- Edit passwords
- Delete passwords
- AES-256 encryption
- Master password
- Import / Export
- javaFX destop application

## Projects structure

```
OmniPass/

```
